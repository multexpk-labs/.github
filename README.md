## Engineering Journey

MULTEXPK LABS grew from a long-running hands-on engineering journey beginning around **2011**.

Early work included Linux, security-oriented tooling, code analysis, reverse-engineering and software experimentation. Over time the focus expanded into application development, PHP/Laravel, Linux infrastructure, VPS and cloud systems, automation, SaaS platforms and hosting technology.

More recently, the work has expanded into NLP, machine learning, local LLMs, AI agents, inference infrastructure and AI-assisted development.

The journey is documented in:

**[Zainjee — Engineering Journey & Research](https://github.com/multexpk-labs/Zainjee)**
